# Space tab imagery

- `worldmap.jpg` — NASA "Blue Marble" composite of Earth, equirectangular
  (Plate Carrée) projection. **Public domain** (NASA imagery is not copyrighted;
  see NASA media usage guidelines). Downsized/recompressed for the app; the base
  map for the live ISS ground track.
  https://commons.wikimedia.org/wiki/File:Blue_Marble_2002.png

- `iss.png` — an original, simplified ISS station icon drawn for this app (solar-array
  wings + central body). Not a photo: a photograph of the station reads as an
  illegible grey lattice at map-marker size, so a bold icon is used instead.
